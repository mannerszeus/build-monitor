
## 원칙
1. 실제 GitHub/코드/CI 상태를 기준으로 한다.
2. UNKNOWN을 PASS로 바꾸지 않는다.
3. 진행 중인 변경을 덮어쓰지 않는다.
4. DB/Auth/Secret/Production 변경은 별도로 명시한다.
5. 테스트 실패와 known issue를 숨기지 않는다.
